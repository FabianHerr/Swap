# 💱 Swap – P2P Currency Exchange (In Progress)

Swap is a peer-to-peer (P2P) web application that allows users to connect and exchange currencies locally, safely, and instantly.  
Unlike traditional intermediaries, Swap directly connects people who want to trade foreign currencies in cash, helping them save on exchange fees and rates.

> ⚠️ **Note:** This project is currently in progress.

---

## 🌟 Features
- 🔎 **Find Traders Nearby** – Connect with users in your local area for in-person exchanges.  
- 💬 **Messaging System** – Chat securely with other users to arrange details.  
- 📊 **User Profiles & Reputation** – Build trust with ratings, transaction history, and verification.  
- 🔐 **Secure Authentication** – JWT-based login and session management.  
- 🎨 **Modern UI** – Clean, minimal interface with responsive design.

---

## 🛠️ Tech Stack
- **Frontend:** React, Bootstrap, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JSON Web Tokens (JWT)
